# Emma's Lab

This is Emma's work lab, run by CC. Emma never touches git, folders, or commands. Everything here happens because Emma talked to CC in plain English, or dropped a file in.

## The map

| Folder | What it's for |
|---|---|
| `daily/` | One file per day. Everything to do and remember lives here. Today's file is always the open one. |
| `inbox/` | Drop anything here: PDFs, photos, spreadsheets, voice memos. |
| `inbox/emails/` | Saved emails, waiting to be sorted. |
| `outbox/` | Finished drafts and letters, ready to download and send. |
| `properties/` | One knowledge card per property: owner, contacts, vendors, the things worth remembering. |
| `tasks/` | Recurring jobs (rent-ups, CAM letters, aging review, and so on), each with its own folder once it's actually come up. |
| `completed/` | Closed daily files. |
| `_archive/` | Anything processed or retired. Nothing ever gets deleted. |

`CLAUDE.md` is the rulebook CC follows. Emma shouldn't need to open it, but it's there if curious.

## How to talk to CC

Just say it plainly. A few examples:

- **"Sort them out" / "Triage these"** — CC reads every email in `inbox/emails/`, pulls out the to-dos, and hands back drafts, letters, or call scripts.
- **"What's my day?"** — CC gives two lists: what needs Emma's decision, and what CC can just handle (and offers to do it).
- **"I need to remember to..."** — CC drops it straight into today's daily file.
- **"What did I say I'd do about [thing]?"** — CC searches the daily files and quotes back exactly what was said and when.
- **"Recap"** — a tight rundown of what got done, what didn't, and what's carrying forward.

CC drafts everything. Emma always hits send. Nothing goes out, gets overwritten, or costs money without asking first.
